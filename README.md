# DevSim - Multi-Device Responsive Simulator

เครื่องมือจำลองหน้าจอ Responsive Web Simulator สำหรับนักพัฒนาและผู้ออกแบบเว็บไซต์

## 📖 คู่มือการใช้งานฉบับเต็ม
สามารถอ่านคู่มือการใช้งานอย่างละเอียดได้ที่: [**MANUAL.md**](MANUAL.md)

## คุณสมบัติเด่น
- 📱 **หน้าจอจำลองอุปกรณ์ยอดนิยม:** iPhone 17 ทุกรุ่น, iPad, แล็ปท็อป และเดสก์ท็อปมอนิเตอร์
- 📐 **ปรับขนาดอิสระพร้อมล็อคสัดส่วนตามรุ่น (Aspect Ratio Lock):** ลากที่มุมขวาล่างเพื่อย่อ-ขยาย พร้อมปุ่มสลับ 🔒/🔓 และปุ่มรีเซ็ตขนาด ↩
- 🖐️ **ลากย้ายอิสระ:** คลิกค้างที่แถบหัวเครื่องเพื่อย้ายไปวางตำแหน่งใดก็ได้บนกระดานแคนวาส
- 🔗 **ระบบแชร์หน้าจอ (Share Workspace):** รองรับการแชร์ในวง Wi-Fi, สแกนด้วย QR Code บนมือถือ และแชร์พร้อมพิกัดหน้าจอ
- 🔍 **Zoom & Smart Fit All:** ปรับขนาดภาพรวมให้พอดีหน้าจอมอนิเตอร์อัตโนมัติ ไม่ล้นตกขอบล่าง
- 🚀 **Auto-Deploy to Vercel:** อัปเดตออนไลน์อัตโนมัติผ่าน GitHub ตลอด 24 ชม.
